'Mi primera aplicación, llamada HelloWorld, fue desarrollada utilizando Expo, React Native'.

Autor: andreimi jesus montero heredia.

Esta aplicación tiene como objetivo poner en práctica los conocimientos sobre componentes, propiedades (props), el estado mediante useState y los estilos utilizando StyleSheet.

Para desarrollar el proyecto se utilizaron las siguientes tecnologías: Expo, React Native, Node.js y pnpm.

Para instalar las dependencias del proyecto, se utiliza el comando pnpm install. Para ejecutar la aplicación, se utiliza pnpm start.

Finalmente, se debe escanear el código QR que aparece al iniciar Expo utilizando la aplicación Expo Go, para abrir y visualizar el proyecto desde el celular.
